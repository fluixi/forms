# @fluixi/forms-zod

Turn a [Zod](https://zod.dev) schema into `@fluixi/forms-core` validators, with errors reported by path, or build a typed form from it with `fromZod`.

Part of [`@fluixi/forms`](https://www.npmjs.com/package/@fluixi/forms), reactive forms for Fluixi.

## Install

```sh
npm install @fluixi/forms-zod
```

See the [`@fluixi/forms`](https://www.npmjs.com/package/@fluixi/forms) package for the full guide.
